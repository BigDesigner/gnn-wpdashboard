# Engineering Standards & Constitution — GNN WPDashboard

- **Confidence**: Verified

## Code Quality & Conventions
1. **PHP Code Style**: WordPress Coding Standards (WPCS) compatible. Indentation with tabs, strict typed parameter checks, and explicit return types.
2. **Language Isolation**:
   - Interactive chat messages and reports: Turkish (`tr`).
   - Project specifications, memory bank files, code docstrings, and commits: English (`en`).
3. **New Plugin Registration**: Every new plugin integrated into GNN WPDashboard must follow `.agents/gnn-dashboard-new-plugin-guide.md` (5 categories, unique banner pattern, 100% white solid icon badges, syntax verified with `php -l`).
4. **Git Hygiene**: Clean commit messages following conventional commit standards (`feat:`, `fix:`, `chore:`).
