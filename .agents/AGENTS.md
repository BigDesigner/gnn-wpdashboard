# Agent Rules — GNN WPDashboard

- **No Fluff**: Omit unnecessary pleasantries. Be direct, concise, and focused on production-ready code.
- **Language**: Interactive messages and final reports MUST be in Turkish (`tr`). All `.memory-bank/`, `.specs/`, `.agents/`, and `.tasks/` files MUST be in English.
- **Strict Verification**: Always verify PHP syntax and WordPress hooks.
- **Strict Planning Guardrail**: In Planning Mode, do NOT run file edit tools and execution commands in the same turn after producing a plan with feedback request.
- **New Plugin Integration Standard**: When adding any new plugin or theme to GNN WPDashboard, strictly follow `.agents/gnn-dashboard-new-plugin-guide.md` (register in `$default_repos`, select from the 5 strict categories, create a unique CSS banner pattern in `admin.css`, maintain 100% solid white card icon badges, and verify PHP syntax with `php -l`).
